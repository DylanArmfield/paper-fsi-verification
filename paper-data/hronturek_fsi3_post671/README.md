# Hron–Turek FSI3, corrected set-up, after solids4foam PR #671

These are the QoIs behind Table `tab:hronturek_corrected` (1x′–4x′) and the #671 A/B statement in the text.
Every case was generated by `paper-data/hronturek_production_scripts/ht_coupled.py` (636d567c6) from the TurekHron2006 tutorial at `30d6e22f3`. The production study used the same generator and tutorial.
The QoIs were extracted with `ht_coupled_analysis.py` (same branch, `636d567c6`) using `--t-end 6`, i.e. five u_y periods before t = 6 s.

- `corrected_sequence_post671.csv`: standard solid, build `206437983` (after #671).
  - 1x′: macOS (Clang), 8 ranks, t = 0–6.2.
  - 2x′: macOS (Clang), 8 ranks, t = 0–7.
  - 4x′: UCD Sonic (Xeon 6542Y, GCC), 32 ranks, t = 0–6.2.
- `ab_671_2x.csv`: 2x′ on macOS with three variants:
  - standard solid, build `ba563ba6a` (immediately before #671). It reproduces the paper's earlier Linux 2x′ row to 0.2 %.
  - standard solid, build `206437983`.
  - cubic high-order solid (p = 3), build `206437983`.

The 8x′ level has been computed only before #671 (`../hronturek_production_coupled_8x_runs.csv`).
